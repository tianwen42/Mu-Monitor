## 每次开发的固定流程

```text
选择一个未完成任务
→ 修改代码
→ Debug 构建
→ 运行和调试
→ 增加或更新测试
→ Release 构建
→ 更新 dist
→ Git 提交
→ 勾选 Todo
```

建议提交信息：

```text
feat(ui): add monitoring dashboard
feat(simulator): add tcp device simulator
feat(network): add tcp client state machine
feat(protocol): add binary frame decoder
feat(storage): add sqlite telemetry repository
feat(alarm): implement alarm state machine
feat(modbus): add modbus tcp adapter
feat(mqtt): add mqtt transport
test: add protocol and alarm tests
chore(package): add windeployqt release script
```
